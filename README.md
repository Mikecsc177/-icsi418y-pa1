Task List Mananger- The application allows you to write a list of tasks that need to be completed. These can be assigned a severity from low to high. This is also indicated by color red for high priority, green for low, and yellow for medium priority tasks. 
Once completed they will be marked with a horizontal line. Tasks can also be deleted fully to make room for more. 

How to use- To run the program simply enter any task, assign it a priority, then click add task to have it added to a list of tasks managed by you. 

There are currently no known issues.
